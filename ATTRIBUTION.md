# Attribution

RIFT DROP 3D is an original procedurally rendered 3D arcade game. Game models, tower sections, hazards, scoring rules, UI, and particles were authored for this project.

The Android launcher icon is a custom XML vector drawable. No third-party game models, commercial images, or sound recordings are bundled.

The browser title and design are independent of third-party helix-drop games. Standard Web APIs, Android WebView, Android Gradle Plugin and GitHub Actions are platform tooling.
